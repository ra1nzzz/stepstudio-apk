# Step Studio for Android

`studio.stepx.com` 的 Android 客户端安装包（原生 WebView 壳）。

## 下载

在 Releases 中下载 `StepStudio.apk`。

## 应用信息

| 项 | 值 |
| --- | --- |
| 应用名 | Step Studio |
| 包名 | com.stepstudio.app |
| 版本 | 1.0.0 (versionCode 1) |
| minSdk / targetSdk | 21 / 34 |
| 体积 | 约 37 KB |

## 功能

- 直接加载 https://studio.stepx.com/
- 返回键在网页内回退
- 站外链接交由系统浏览器打开
- 支持网页内选择文件上传
- 登录状态（Cookie）持久化
- 网页下载交由系统下载器处理
- 语音输入时按需申请麦克风权限
- 断网时提供重试页

## 安装

1. 手机下载 APK
2. 允许「安装未知来源应用」
3. 点击安装
